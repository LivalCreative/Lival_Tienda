# Lival Creative Studio · Tienda

Sitio público: https://villamichel.github.io/Lival_Tienda/

- `index.html` — inicio con las secciones.
- `duende/` — sección especial Travesuras del Duende (carrito, anticipo, pedido por WhatsApp).
- `navidad/`, `productos/` — secciones (muy pronto).
- `ocupacion.json` — fechas ocupadas y horas pendientes, generado desde el tablero Pedidos 3D con `tools/ocupacion.py`. No contiene nombres ni montos.
